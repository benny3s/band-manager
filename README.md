# 애쉬만루트 합주 일정 취합

그루브 사당점 C룸 일요일 합주 가능 날짜를 멤버들에게 받는 페이지.
GitHub Pages(정적 페이지) + Google Apps Script(저장) + Google 스프레드시트(데이터).

```
멤버 휴대폰 ──► GitHub Pages (index.html)
                      │  fetch
                      ▼
              Apps Script 웹앱 (/exec)
                      │
                      ▼
              Google 스프레드시트 「응답」 시트
                      │
                      ▼
                   Claude 가 읽고 집계 → 그루브 예약
```

## 데이터 형식

`응답` 시트 — A열 이름, B열부터 날짜(`YYYY-MM-DD`)

| 이름 | 2026-10-04 | 2026-10-11 | … |
|---|---|---|---|
| 홍길동 | O | X | |
| 김철수 | 09-12 | O | |

- `O` — 기본 시간(10~12시) 가능
- `X` — 불가
- `09-12`, `14-16, 19-21` — 그 시간대만 가능 (끝 시각은 종료시각)
- 빈칸 — 아직 응답 안 함

## 설치

### 1. Apps Script 배포
1. 스프레드시트 열기 → **확장 프로그램 → Apps Script**
2. `apps-script.gs` 내용 붙여넣기 → 저장
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 없으면 멤버들이 못 씁니다
4. 권한 승인 → 나오는 `https://script.google.com/macros/s/…/exec` 복사

### 2. 페이지 설정
`index.html` 맨 아래 `CONFIG` 수정:
```js
members: ["이름1", …],          // 멤버 6명
endpoint: "붙여넣은 /exec URL",
weeks: 12                        // 앞으로 12주치 일요일 자동 표시
```

### 3. GitHub Pages
저장소 Settings → Pages → Source: `main` / root → 저장.
몇 분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 유지보수

- 날짜는 **열 때마다 자동 계산**됩니다. 매번 고칠 필요 없음
- 멤버가 바뀌면 `members` 배열만 수정 후 push
- 시트를 직접 고쳐도 됩니다. 페이지가 그대로 읽어옵니다
- 응답 사고 시 스프레드시트 **파일 → 버전 기록**으로 복구

## 주의

- 저장소는 **공개**입니다 (무료 GitHub Pages는 공개 저장소만 가능).
  소스와 `/exec` 주소가 공개되므로, 주소를 아는 사람은 시트에 쓸 수 있습니다.
  밴드 단톡방 밖으로 링크가 새면 낙서가 가능하니 그때는 새로 배포하세요.
- 응답 데이터 자체는 스프레드시트에 있고 저장소에는 남지 않습니다.
